What is repaired

Five things

Replacement is now one flag, for every insurer

It only fired on Guardian policies, so replacing another insurer’s cover raised nothing at all. It now fires on any insurer — and says one thing rather than five: “This replaces cover the client already has. The disclosure form must be completed and signed before the new application goes in.” The statute references have come out of the advisor’s screen; a wall of citations mid-appointment gets skipped, which is the opposite of what a flag is for.

The Central Bank disclosure form

Did not exist in the live build. It now renders automatically whenever a replacement is detected, prefilled from the fact find — insurer, year, type, sums, premiums — with the verbatim caps warning, the nineteen-row comparison, the cost table and three signature blocks.

Guardian’s page five stops at four rows

Recommendations five and six were overrunning the printed form. Page five now hard-stops at four and prints a line saying where the rest are; the overflow is set out in full on the addendum with priority, need, plan, amount, premium and reason.

The reason that would not save

Premchand’s bug. dec{N}Reason had no schema entry, so every reason an advisor typed was silently dropped on the way to the sheet — and the checks then re-raised “no reason given” on a case that had just been fixed. The reason is the compliance artefact; it now has a column and it saves.

Seventeen needs, and the addendum that carries them

Seventeen rules read the fact find the advisor has already filled in and surface what nobody asked about — the business with no buy-sell, the mortgaged rental, the uninsured card, the child with nothing costed — each with the question that opens it. Four go on Guardian’s form; the rest go in the advisor’s bag as the next appointment.

Getting it in

Five steps, in a browser

1

Download it above

Keep the filename exactly FFPROJECT.html.

2

Open the repo

github.com/RickyRampersad/fact-find-analyzer → Add file → Upload files.

3

Drag it in — and commit to a NEW branch

At the bottom choose Create a new branch for this commit. Call it fixed-fact-find. Not main.

4

Let Netlify build the preview

It will produce a URL like deploy-preview-1--factfinds.netlify.app. Open a real case on it — put a replacement through, print the pack, check the addendum.

5

Only then, merge

Open the pull request GitHub offers and merge it. Netlify rebuilds the live site and every advisor has the fixed form on their next reload.
