Pulling intakes into the tracker
One link, then one click

Every branch intake writes a complete Recruit Tracker record. To load the ones you have not pulled yet, open <your Apps Script /exec URL>?export=new&key=<EXPORT_KEY>, save the file, then use Import inside the Recruit Tracker. Candidates arrive with contact details, source, background and five of Form A's eight rows already filled in — from the candidate's own answers, unverified. Setup lives in apps-script/careers-intake.gs.

Where the data actually lives

The Recruit Tracker keeps candidate files in this browser only — nothing is uploaded and nothing is stored on the website. That means a file opened on the BMA's laptop is not visible on the BM's phone. Use Export in the tracker to hand a file over, and export a backup before clearing browser data or changing machines.
