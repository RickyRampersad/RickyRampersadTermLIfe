Before you ask

Yes — it really is this simple.

✓ Nothing to install

It is a web page. No app, no account to create, no password to invent and forget. Your code is the whole of it.

✓ Nothing to break

You cannot change a figure by accident — the screen only shows you what we hold. If something looks wrong, tell us and we correct it.

✓ Nobody else’s business

An employee code shows one person. An employer code shows one company. Every sign-in is logged, and the code itself is never shown back.

Please ask

These are fair questions.

You should have the answers before the policy is issued rather than after — so ask us, or ask RIA, the guide built into the page.

What will this be worth when I retire?And how much of it is guaranteed.
What happens if I leave this employer?Ask before you need to know.
If I die before retiring, who receives it?And is that still the person I named.
Can I change what I put in, or pause it?Usually yes — we will tell you how.
Can we put in more for someone?There is a ceiling, and we work it out exactly.
What do the charges cost me?Straight answer, from the contract.
