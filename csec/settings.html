Reset somebody else's PIN

Anyone signed in on this device can reset any other profile's PIN here. That is deliberate — a child who is locked out should not need a support call — and it is why the PIN keeps profiles apart rather than keeping secrets.

Moving up a form

At the end of the school year, move the student up. Everything already learned carries forward — she has not forgotten Form 2 mathematics — but the year is stamped into the record, the syllabus for the new form opens up, and the old year stays visible on the KPI timeline for all five years.

Group code
Who can see this. Anyone with the code can read and change this group's names and practice scores. There is no password behind it. Treat it like a house key — give it to family and to your child's teacher, and to nobody else. If it gets out, delete the group here and make a new one.

Backup & moving devices

There is no server behind this hub, so progress lives in this browser and nowhere else. Clearing your browser data erases it. Export a backup file now and again — and always before changing phone or laptop.

Clearing data

Both of these are permanent and cannot be undone. Export a backup first if there is any doubt.

What "sign in" means here. These pages are static files served from a web host, with no database behind them. A profile and its PIN are stored in this browser, which keeps profiles apart on a shared device — it is not a security boundary, and anyone with the device and a little determination can read the stored data. Do not put anything confidential in a name or a note.
