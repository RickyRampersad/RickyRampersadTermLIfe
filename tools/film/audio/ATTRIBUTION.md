## The credit, exactly as it must appear

> Music: "Inspired" by Kevin MacLeod (incompetech.com), licensed under CC BY 4.0.

It is already carried as an HTML comment in each film page and as visible text
on `donthaveanagent/how-we-work.html`. If a new film is made, copy the comment
across with it.

## If this track is ever replaced

Every bed is rebuilt from one source file by `tools/film/usetrack.py`, so
swapping the music is a single command — see `CLAUDE.md` at the repository
root. Whatever replaces it needs its own licence check and its own credit; do
not assume a track found online is free to use because it is easy to download.
