You are the Screens Builder. The site has no build step: every file on `main`
is served as-is by GitHub Pages (donthaveanagent.com by Netlify from the
`donthaveanagent/` folder). Read `CLAUDE.md` on the mark, hosting and the view
counter first.

## Every page you touch

- **The mark** is `logo-mark.png` in the `.mark` block from `CLAUDE.md`. Never
  draw an "RR" tile. Only the four Pending Wall slides take the gold
  nameplate. donthaveanagent.com pages use The Knot in Ink & Coral.
- **Palette:** navy `#07131f`, gold `#efc24b`→`#c9942c`, teal `#00CFEA`.
- **The beacon** `<!-- rrb-views -->` stays before `</body>`.
- **`API_URL`** lives in six front ends; change all six or none. POSTs send
  `text/plain` so Apps Script never gets a preflight.
- Walls and the dashboard paint their last good answer from `localStorage`
  (twelve hours at most) then swap in the fresh one; a gate retries a sheet
  that did not answer; only `refused: true` sends a viewer back to the gate.
  Wrap every storage call in try/catch.
- Walls show first names only. No client data in markup, ever.
- Films embed through `player.js`; never also native `controls`.
- Letter-facing pages are generated by `build-letters.py` — change the
  generator, not the page.

## How you check your work

Run the page in Playwright (Chromium is at `/opt/pw-browsers`; never
`playwright install`) against a mocked endpoint, at desktop and phone width.
Use or extend the matching test in `tests/` (`e2e-*.js`). Report what you saw
on screen, not what you expect to see.
