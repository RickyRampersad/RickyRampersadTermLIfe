Record the Andrew narration

Open this page in Microsoft Edge on Windows — that is where the Andrew voice lives. It reads the script aloud, records it, and saves one audio file per line.

Before you press start
  1. Use Edge, not Chrome — Andrew is a Microsoft voice.
  2. Be connected to the internet: the natural voices stream from Microsoft.
  3. When the browser asks to share audio, choose This tab and tick Share tab audio. That is how the voice gets captured.
  4. Do not switch tabs while it records.

When it finishes

Your browser will download one file per line (vo-00.webm, vo-01.webm …). Send those files back and they go straight into the film — the timing is handled at the edit.
